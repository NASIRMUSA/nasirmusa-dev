# Nasir Musa Portfolio

A high-performance, SEO-optimized professional portfolio for Nasir Musa, built with Next.js 16 and TailwindCSS 4.

## Key Features
- **Performance Optimized**: Achieved through Server Components, CSS-only animations, and viewport-aware rendering.
- **Modern Tech Stack**: Next.js 16 (App Router), React 19, TailwindCSS 4, Lucide React.
- **Responsive Design**: Premium dark mode aesthetic with glassmorphism and balanced typography.
- **Conversion Focused**: Integrated WhatsApp contact form and strategic CTAs.

## Performance Strategies
- **Server Components**: Minimized JavaScript bundle by moving heavy sections to the server.
- **CSS Animations**: Replaced JS-heavy animations with CSS for instantaneous Largest Contentful Paint (LCP).
- **Viewport Optimization**: Uses `content-visibility: auto` to skip rendering of off-screen content.
- **Zero-Dependency Animations**: Removed Framer Motion in favor of lightweight CSS transitions.

## Getting Started
First, install dependencies:
```bash
pnpm install
```

Then, run the development server:
```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
